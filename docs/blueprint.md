# **App Name**: Nomad Navigator

## Core Features:

- Hotel Search: Allow users to search for hotels using Travelpayouts API.
- Flight Search: Enable users to search for flights using the Travelpayouts API.
- Combined Booking: Offer the option to book both hotel and flight within the same transaction flow, but via calls to the separate APIs.
- User Account: Users create an account with a profile to save and recall preferences, booking history, and payment methods.
- Smart Recommendations: Use generative AI tool to provide tailored hotel and flight recommendations, improving the relevance of offers.

## Style Guidelines:

- Primary color: Soft blue (#75A9FF) to evoke trust and serenity associated with travel.
- Background color: Very light blue (#F0F5FF) to maintain a calm and airy feel.
- Accent color: Warm orange (#FFA64D) to highlight key actions and important information, suggesting adventure and excitement.
- Font: 'PT Sans', a humanist sans-serif for both headlines and body text.
- Use a set of modern, outlined icons to represent travel-related elements like hotels, flights, destinations, and activities.
- Employ a clean, card-based layout with ample whitespace for an intuitive user experience, making it easy to scan and interact with search results.
- Incorporate subtle animations such as loading spinners and transition effects to provide visual feedback and enhance user engagement during search and booking processes.
